# Descrizione della Postazione di Laboratorio

## Hardware

La mia postazione di laboratorio è composta da un PC con sistema operativo **Windows 11**. Il computer è dotato di un processore Intel i7, che garantisce elevate prestazioni per lo sviluppo e la gestione di applicazioni.

Inoltre, il PC dispone di *16 GB di memoria RAM, lo schermo è un monitor Full HD da 24 pollici.

## Software Installato

Ho installato **Visual Studio Code**, che è il mio editor principale. Sto usando la versione 1.9x, che ha molte funzionalità utili.
Per programmare in Java, utilizzo il *JDK 17*. Per il controllo di versione, invece, uso Git 2.4x. Entrambi sono strumenti indispensabili per il mio lavoro.

### Strumenti Aggiuntivi

Per il lavoro con i dati e la programmazione scientifica utilizzo estensioni di Visual Studio Code per migliorare la produttività, come il supporto per Python e Java.
