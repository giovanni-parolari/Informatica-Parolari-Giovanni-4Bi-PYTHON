**Nome:** Giovanni Parolari · **Classe:** 4Bi
**Materia:** Informatica · **Anno scolastico:** 2026/2027
 
## Scopo del repository
Raccoglie le consegne del Laboratorio di Informatica svolte durante l'anno
scolastico: ambiente di lavoro, Markdown e Jupyter, Python di base e
avanzato, gestione dei file, programmazione a oggetti, programmazione
concorrente e di rete. Ogni modulo ha una cartella dedicata.
 
## Convenzione di denominazione delle cartelle
Ogni cartella di modulo segue lo schema `M<numero>_<argomento>`: `<numero>`
è il numero progressivo assegnato dal docente, `<argomento>` è una sigla
breve senza spazi che ne riassume il contenuto (es. `M0_ambiente`).
 
## Dove si trovano le consegne
Dentro la cartella del modulo corrispondente: file `.py` per gli esercizi
di programmazione, file `.md` per relazioni e verifiche.
 
```
.
├── M0_ambiente/          ├── M4_Funz_Moduli_PY/
├── M1_markdown_jupyter/  ├── M5_GestioneFile_PY/
├── M2_PY_Iniziale/       ├── M6_OOP_PY/
├── M3_StruttureNativePY/ ├── M8_Prog_Conc_e_Rete/
├── .gitignore            └── README.md
```
